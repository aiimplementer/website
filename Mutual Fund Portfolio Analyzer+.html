Privacy, by design

Your CAS statement never leaves your device

A CAS has your PAN, folio numbers, holdings, and contact details on it. That's not something to hand to a server. Analyzer+ was built so it never has to.

🔒

No upload, ever

Your CAS PDF is parsed on your own machine (or in your browser for the free version). It is never sent to us or any third-party server.

⚡

Minimal, one-time network use

The only online step is fetching current NAVs to value your holdings — your CAS itself is never part of that call. Once a report is generated, you can browse it offline; refresh NAVs again only when you want updated prices.

👤

Only Email activation required

Only email activation is required to try the free version. The licensed edition activates locally — it doesn't sync your portfolio to an account in the cloud.

📄

You decide what's shared

The only data that ever leaves your device is a PDF report you deliberately export — nothing is transmitted in the background.

System requirements

Windows compatibility

MF Portfolio Analyzer Plus ships as a native Windows installer. Here's what it needs to run.

OS

Windows 10 & 11

Verified on Windows 10 (version 2004/20H2 or later) and Windows 11, 64-bit only. Not tested on Windows Server editions or 32-bit Windows.

🌐

WebView2 runtime

Requires the Microsoft Edge WebView2 Runtime, which powers the app's interface. It comes pre-installed on Windows 11 and is delivered via Windows Update on current Windows 10 — on an older, un-updated machine it may need a quick separate install.

📦

One-click installer

Distributed as a single MFPortfolioAnalyzerPlus-Setup.exe. No Python, no dependencies to install manually — it's a self-contained desktop app.

🔑

No admin rights needed

Installs and runs entirely under your Windows user account — nothing requires elevated or administrator privileges.

Known Windows 11 quirk: on some machines, an unrelated OS-level bug (tied to update KB5019980) in Windows' "Suggested Actions" clipboard feature can briefly spam the terminal or freeze the window when a text field gains focus. Analyzer+ automatically applies the same workaround Windows Settings itself uses when you turn Suggested Actions off — no action needed on your end, and it doesn't affect app functionality.
